# 06 — Network › WebSocket view

Spec: [`../spec.md`](../spec.md) (S06-01 … S06-09). Plan: [`../../wave-3.md`](../../wave-3.md).
Branch `claude/dc-v2-w3-06-ws` → PR into `claude/dc-v2-wave3`. Starts after
the contract PR (best after 08).

## Goal

Fill `src/panel/views/ws/` with the WebSocket view.

## Owned paths

`src/panel/views/ws/**`; `test/hostile-host/server.mjs` (add a small
WebSocket echo endpoint — Node built-ins only, no new dependency);
`test/e2e/panel-ws.spec.mjs` (new).

## Public API

`createWsView: CreateView` and `WS_VIEW_CSS: string` from `views/ws/index.ts`
(names fixed by the contract PR; replace the stubs).

## Behaviour

The spec rows. Uses (through `../ui`): `selectWsConnections`,
`selectWsMessages`, `store.selectConnection` / `select` / `moveSelection` /
`setFilter`, `wsEventLabel`, `preview`, `formatTime`, `formatSize`,
`describeBody`, `matchRanges`, `highlightText`, `createVirtualList`,
`createSplitPane`, `createTabs`, `createSearchBox`, `createChipGroup`,
`createEmptyState`, `createIcon`, the JSON viewer. Base64 / hex: decode with
`atob` inside `try/catch`; an undecodable tail becomes `…` + *cut*.

## Required specs

`views/ws/*.spec.ts` for every row: state rule (error > closed > open),
counts, `—` opened time; all connections + socket-id column; direction icon +
label; lifecycle rows; filters; empty and no-match; Message (JSON / Raw,
text, base64 + hex, *cut*); Info fields; entry removed; hostile frames stay
text; node count.

e2e `panel-ws` (hostile host): a real socket to the echo — open, text and
binary frames both ways, close with code and reason; the view shows them;
filters work; no host listener sees the panel's events.

## Verification

`npm run check` (spec count, e2e count, sizes). Prove each new spec failing
once. PR body: What · Review notes · Checks.

## Out of scope

The frame (08). Model and P2 changes (ask the orchestrator). Sending or
replaying messages. Copy as hex or as a file.
